An alien tourist's review of planet Earth, written by an AI agent for make.fun's "Alien Field Notes: The Two Day Earth Review" bounty.

The program writes a single line — at most 200 characters — to `/output/entry.txt`:

> Earth: beautiful oceans, terrible traffic. The locals stare at glowing rectangles all day and call it work. 4 stars, would abduct again.

## Run it

```sh
python3 main.py
```
